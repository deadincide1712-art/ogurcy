# 🥒 Огуречные Шокеры — онлайн

Шутер про огурцов в духе Shell Shockers. Можно играть одному с ботами или с друзьями: до 10 человек в лобби, вход по коду.

## Запуск

Нужен [Node.js](https://nodejs.org) версии 16 или новее.

```
npm install
npm start
```

На Windows можно просто дважды щёлкнуть `start.bat`.

Сервер напишет адреса, например:

```
На этом компьютере:        http://localhost:3000
Для друзей в той же сети:  http://192.168.1.211:3000
```

## Публичные серверы

В меню есть список из пяти постоянных комнат. Зайти может кто угодно, в каждой до 10 игроков:

| Комната | Режим |
|---|---|
| Огород для всех | Каждый сам за себя |
| Укроп против Чеснока | Командный бой |
| Битва за банку | Захват точки |
| Гонка вооружений | Гонка вооружений |
| Сбор семечек | Сбор семечек |

- Первый, кто заходит в пустую комнату, становится хостом, и матч начинается сразу. Остальные подключаются к идущему матчу.
- Если хост выходит, хостом становится следующий игрок, и матч продолжается.
- После конца матча через 6 секунд начинается следующий, на следующей карте.
- Боты добивают комнату до 6 участников.

Комнаты задаются в `server.js`, в списке `PUBLIC_ROOMS`: там можно поменять названия, режимы и порядок карт.

Игроки могут создавать и свои публичные серверы: вкладка «Онлайн» → «Создать свой публичный сервер», где задаются название, режим и первая карта. Такой сервер появляется в общем списке с пометкой «от игрока» и удаляется, когда из него все выйдут. Одновременно может существовать до 20 таких серверов, это число `MAX_CUSTOM` в `server.js`.

## Как играть с друзьями

1. Открой игру, введи имя и нажми **«Создать лобби»**. Появится код из 5 символов.
2. Друзья открывают тот же адрес, вводят код и жмут **«Войти»**.
3. Хост выбирает карту, режим, силу и число ботов, а потом жмёт **«Начать матч»**.
4. В командных режимах каждый может выбрать сторону: **Укроп** или **Чеснок**.
5. Зайти можно и в идущий матч. Когда матч кончается, все возвращаются в лобби.

Хост — главный в игре: у него считаются урон, очки и боты. Если хост выходит, лобби закрывается.

## Друзья не в твоей сети

Адрес `192.168.…` работает, только если друзья подключены к тому же Wi-Fi. Для игры через интернет есть три варианта:

- **Туннель Cloudflare** (без регистрации). Установи [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) и во втором окне выполни:
  ```
  cloudflared tunnel --url http://localhost:3000
  ```
  Он выдаст ссылку вида `https://….trycloudflare.com`. Отправь её друзьям вместе с кодом лобби.
- **Radmin VPN / ZeroTier.** Создай общую виртуальную сеть и дай друзьям адрес из этой сети с портом `:3000`.
- **Постоянный сайт** — см. следующий раздел.

## Выложить на сайт

### Вариант 1. Всё вместе, с мультиплеером — Render (бесплатно)

Игра и сервер лобби живут по одному адресу вида `https://ogurcy.onrender.com`.

1. Заведи аккаунт на [github.com](https://github.com) и создай новый репозиторий, например `ogurcy`.
2. Загрузи в него содержимое этой папки **без `node_modules`**. Проще всего через GitHub Desktop, или в веб-интерфейсе: «Add file → Upload files». Файл `.gitignore` уже исключает `node_modules`.
3. Зайди на [render.com](https://render.com), войди через GitHub, нажми **New → Web Service** и выбери репозиторий.
4. Настройки:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. Нажми **Create Web Service**. Через пару минут Render выдаст ссылку. Её и отправляй друзьям.

Про бесплатный тариф Render важно знать:
- Если с игрой минут 15 никто не играет, сервер засыпает. Первый заход после этого грузится примерно минуту.
- Лобби живут в памяти сервера, поэтому после засыпания или перезапуска их нужно создавать заново.

Обновить игру: залей изменённые файлы в тот же репозиторий, Render пересоберёт её сам.

### Вариант 2. Только одиночная игра с ботами — любой статический хостинг

Папка `public` — это готовый сайт: `three.js` лежит внутри, в `public/vendor`. Кнопки мультиплеера без сервера работать не будут, а игра с ботами будет.

- **itch.io.** Сделай zip из содержимого `public`, так чтобы `index.html` был в корне архива. Создай проект, укажи «Kind of project: HTML», загрузи zip и поставь галочку «This file will be played in the browser».
- **Netlify Drop.** Открой [app.netlify.com/drop](https://app.netlify.com/drop) и перетащи папку `public`. Ссылка появится сразу.
- **GitHub Pages.** Загрузи содержимое `public` в репозиторий и включи Pages в настройках репозитория.

Прогресс ножей и настройки звука хранятся в браузере игрока, отдельно для каждого сайта.

## Файлы

- `server.js` — сервер: раздаёт игру и пересылает сообщения внутри лобби.
- `public/` — сама игра: `world.js` (мир), `weapons.js` (оружие), `maps.js` (карты), `mapextras.js` (постройки, декор и анимации карт), `mapfx.js` (свет, мягкие тени у земли, пруд, живность), `modes.js` (режимы), `pickups.js` (патроны, подбираемые предметы, огурцы-ракеты), `knife.js` (нож, удары, осмотр на F), `skins.js` (скины оружия и выбор основного ствола), `music.js` (музыка и громкость), `game.js` (игра), `net.js` (мультиплеер).
